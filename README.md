# Nina Carducci

Projet réalisé dans le cadre de ma formation de développeur web.

## Description

Audit et optimisation du site de la photographe Nina Carducci afin
d'améliorer ses performances, son accessibilité, son référencement
et son fonctionnement.

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Améliorations réalisées

- Correction des bugs JavaScript
- Optimisation des images
- Amélioration de l'accessibilité
- Optimisation du référencement SEO
- Amélioration des performances

## Résultats

Le site a été fortement optimisé sur les performances, l'accessibilité
et le référencement.

Cloner le repository puis ouvrir le projet dans un navigateur.
